# Images du rapport

Déposez ici les images du rapport. Tant qu'un fichier est absent, le rapport
affiche une **case grise légendée** à la place (le document compile quand même).
Dès qu'un fichier existe **avec le bon nom**, il est inséré automatiquement.

## Noms de fichiers attendus

| Fichier                       | Contenu                                  |
|-------------------------------|------------------------------------------|
| `logo-tsp.png`                | Logo Télécom SudParis (page de garde)    |
| `gantt.png`                   | Diagramme de Gantt prévisionnel          |
| `screenshot-dashboard.png`    | Capture de la page Tableau de bord       |
| `screenshot-backtests.png`    | Capture de la page Backtests (formulaire)|
| `screenshot-results.png`      | Capture de la page Résultats (équité)    |
| `screenshot-data.png`         | Capture de la page Données de marché     |
| `screenshot-login.png`        | Capture de la page de connexion          |

> Formats : PNG ou JPG. Si vous utilisez un autre nom/extension, ajustez l'appel
> correspondant dans `rapport.tex` (commandes `\figph{...}` et `\logoph`).
